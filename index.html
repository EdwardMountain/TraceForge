TraceForge V3.02

A magnitude compensation tool for transfer function measurements through RF systems or other non-transparent measurement paths. By DoDo7. Copyright (c) 2026 Edoardo Montagnoli. All rights reserved.

TraceForge combines the calibration curve of your measurement microphone with the magnitude response of a wireless (RF) system or any other non-transparent measurement path. The result is a new calibration curve: load it as the mic correction curve in your measurement software, and measurements through the RF path line up with measurements through a cable.

How to use it

  1. Load the mic calibration file in the Mic calibration box (drag it onto the box or press Load), or press Flat 0 dB to use a flat curve.
  2. Measure the RF system against a cable or reference path, export the transfer function as ASCII and load it in the RF / path response box. Press Demo to try TraceForge without a measurement; ↻ makes a new demo curve.
  3. Type the mic, RF / path and custom names. The curve title and the file name are built from them.
  4. The compensation curve is calculated as soon as both curves are loaded, and follows every change. Check the graph, then press Download .txt.

Export modes

  • Mic Correction Mode, Smaart compatible (default): Output = mic calibration + RF / path response. Smaart subtracts mic correction curves internally, so TraceForge writes the response curve itself.
  • EQ Mode, inverted compensation (advanced): Output = mic calibration − RF / path response. Only for software that applies the curve directly as an EQ. TraceForge asks for confirmation before using it. The sign between the two boxes at the top shows the mode in use.

Options

  • Normalization at 1 kHz is on by default for both curves. It removes global level offsets, so the compensation follows only the shape of each curve.
  • Loading a new curve or changing an option updates the output right away. The Parser log shows one summary line for each update.
  • Every time TraceForge opens, curves, names and options start from their defaults. Only the colour mode is remembered.

Files

  • Mic calibration: .txt, .crv, .csv, .tsv and other text formats with frequency in Hz and magnitude in dB.
  • RF / path response: ASCII text export of a transfer function. Only magnitude is used; phase and coherence columns are ignored. .trf files are not supported yet.
  • Comments, headers, metadata and duplicate frequencies are skipped automatically. Open the Parser log to see what was read.
  • The output is a magnitude-only .txt file from 10 Hz to 20 kHz, at the frequencies of the calibration curve. The RF / path response is interpolated on a log-frequency scale.
  • Files are read in your browser and are never uploaded.
